# Инструкции для агентов LasTest

Прочитай [AGENT.md](AGENT.md) перед работой с проектом. Там описаны архитектура, команды запуска и проверки, форматы артефактов и особенности совместной работы CLI и web. Пользовательская документация находится в [README.md](README.md).

Проект переписывания на Rust без Go и разбор ошибки Docker-сборки описаны в [AGENT-ARCHITECTURE.md](AGENT-ARCHITECTURE.md).

- CLI запускается через `python main.py`. Web/API запускается через `uvicorn app.main:app`, а очередь обрабатывает отдельный процесс `python -m app.worker`.
- При изменении задачи проверь её запись и обработчик в `app/services/tool_registry.py`, а также чтение её результатов в dashboard. Сохраняй совместимость с существующими проектами и артефактами CLI.
- Для проверки сканирования используй только явно разрешённые цели. Для обычных проверок используй тестовые данные и временные каталоги. Секреты, SQLite-базы, результаты и логи сканов не добавляй в git.
- Базовые тесты запускаются командой `python -m unittest discover -s tests` после установки `requirements.txt`. Системные инструменты сканирования для них не требуются.
