# Инструкции для агентов LasTest

- LasTest 2.0 — Rust-приложение. `lastest serve` запускает API и встроенный интерфейс, `lastest worker` выполняет задачи, CLI обращается к API. Начальные сведения и ссылки на руководства находятся в [README.md](README.md). [AGENT-ARCHITECTURE.md](AGENT-ARCHITECTURE.md) хранит исходный проект архитектуры и причины перехода на Rust.
- HTTP-маршруты находятся в `src/api/`, очередь и сохранение результатов в `src/db/` и `src/worker/`, реестр и обработчики в `src/tasks/`, сетевые клиенты и проверка целей в `src/net/` и `src/scope/`. При изменении задачи проверь параметры, разрешённые цели, формат результата и чтение его через API.
- Проверяй задачи на локальных фикстурах или явно разрешённых целях. Храни секреты, рабочие базы и результаты вне Git. Сохраняй применённые миграции и совместимость импорта из 1.x. Фикстуры импорта находятся в `tests/fixtures/v2/legacy/`.
- Перед отправкой проверяй `cargo fmt --all -- --check`, `cargo clippy --locked --all-targets --all-features -- -D warnings` и `cargo test --locked --all-targets --all-features`. Для изменений Docker выполни сквозной сценарий из [чек-листа](docs/v2/checks.md).
- Ветка `dev` используется для разработки. GitHub Actions публикует проверенный образ `ghcr.io/lasnet/lastest` при push в `dev`. Для установки передавай Compose ссылку с digest. Исходники 1.x доступны через тег `v1-legacy`.
